Whitted raytracing, 16-ray SIMD packets in WebAssembly, or one thread per pixel in a WGSL compute shader. No BVH, no kd-tree, no grid; no DXR/OptiX/Vulkan-RT, no RT cores. Sphere intersection is something no RT core can do anyway — they only do triangles and BVH nodes; GPUs fall back to shader code for spheres, just like us.
